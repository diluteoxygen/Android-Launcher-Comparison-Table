This table is made to help find a launcher that checks all boxes in terms of need. If you're new to Android theming or Android in general, create a filter below with customizability set to Basic to get started! Credits to [Grabstertv](https://www.reddit.com/user/Grabstertv/) for doing most of the heavy lifting.


## Comparison Basis

We mark launchers on the following properties:

- Price
- Ads/Bloatware
- Update Frequency
- Source Code Availability
- Customisability
- App Drawer Style
- KLWP Support
- Widget Support
- Material You Colors
- Landscape Support
- Foldable/Tablet Support
- QuickSwitch Support
- Supported Android Version
- Privacy Policy

**Notes:**

*▪️ Icon pack support is not listed as a column because every launcher in this table supports icon packs - except those marked with "Less than basic" customisability.*

*▪️ Privacy reports are provided via Exodus Privacy. Accuracy and freshness vary; treat them as a starting point, not a definitive verdict.*

*▪️ The **Landscape Support** column refers to usability in landscape orientation on a phone. The **Foldable/Tablet Support** column refers to dedicated large-screen or foldable layout support, which is a meaningfully different capability.*

## Notes

**Nova Launcher** - Acquired by Instabridge Sweden AB on January 20, 2026. Ads were introduced to the free tier beginning with version 8.2.x. The app's Play Store rating dropped significantly following this change. An updated Exodus Privacy report confirms the presence of 11 trackers, including multiple advertisement trackers (AppLovin, Facebook Ads, Fyber, Google AdMob, Pangle) and analytics/profiling tools. Nova Launcher Prime subscribers have also reported intermittent ad appearances, though this appears to be unintentional.

**Nothing Launcher** - This launcher is exclusive to **Nothing OS V2.5.0+ devices** and is not functional on arbitrary Android devices. Version 3.x requires Android 15.0+; version 4.x (current as of June 2026) requires Android 16.0+. The previous listing of Android 8.0+ referred to a very early version from 2023.

**Lawnchair 15 (Beta)** - Beta 3 was released on April 18, 2026. The launcher is now available both on GitHub and the Play Store (`app.lawnchair.play`). **QuickSwitch is supported on Android 10–15 only**; Android 16 support is not yet available. Lawnchair 16 (targeting Android 16's Launcher3) is in early development on GitHub.

**Stario** - The developer publicly announced in June 2026 their intent to step back from active development, citing Android platform direction. The project remains open source and available. The 🪦 symbol indicates maintenance-only / winding-down status; the app is still usable but should not be expected to receive new features.

**Niagara Launcher** - The developer rebranded as **Mellowdrop Studio** in April 2026, alongside the "Studio Update" (version 1.16.x) which added a theming hub, expanded icon styles, and clock customization. Landscape and foldable support remain partial — basic support was added in 2026 but large-screen layouts are still limited.
